### Mass Pac

A simple emulator of the Pac-Man and Ms. Pac-Man arcade cabinets. This project was created to give me a simple emulator to give me a place to experiment with new emulation ideas.

Currently this project requires rust nightly to build as it uses the `local_waker` feature. Additional unstable features may be added in the future.
